# Contributing

Security reports, reproducible bug reports, and documentation clarifications are
welcome.

Code contributions require a contributor agreement before merge. Shellin Core is
published under AGPL-3.0-or-later, and the copyright holder also uses the same
code under separate commercial or internal terms.

Before opening a code pull request, open an issue or contact the maintainer to
confirm that the contribution is in scope and that the contributor agreement can
be completed.

By contributing, you confirm that you have the right to submit the work under
AGPL-3.0-or-later and, for code changes, under the additional contributor
agreement.
