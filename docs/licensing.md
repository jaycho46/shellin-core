Shellin Core is licensed to the public under AGPL-3.0-or-later.

The copyright holder may also use, distribute, and license the same code under
separate commercial or internal terms. That separate permission is not granted
to the public by this repository.

## Contributions

Code contributions are not merged until the contributor has signed an agreement
that allows Shellin to use the contribution under AGPL-3.0-or-later and under
Shellin's separate commercial or internal license terms.

Bug reports, security reports, and documentation clarifications are welcome
without a code contributor agreement.

## Release Archives

Shellin CLI release archives include:

- Shellin Core's public license and copyright notice.
- A source link for the exact release.
- Third-party module, Go standard library, and Go runtime license notices under
  `THIRD_PARTY_NOTICES.md` and `THIRD_PARTY_LICENSES/`.
